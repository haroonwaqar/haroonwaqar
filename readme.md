### 🚀 Featured Projects

#### 🎬 YouTube Research Analyst
Built a full-stack RAG app for semantically grounded conversations with YouTube lectures, using FastAPI, LangChain, Pinecone, Groq (gpt-oss-120b), Hugging Face embeddings, and Apify, deployed on Heroku. Streamed answers over SSE, isolated each video in its own Pinecone namespace, and cut resting RAM to ~177MB by moving embeddings to a hosted API. Added per-IP rate limiting and prompt-injection guardrails. [Live Demo](https://youtube-research-analyst-33c40f4738cc.herokuapp.com/) · [Code](https://github.com/haroonwaqar/Youtube-Research-Analyst)

#### 🍎 Fruit Classification on ESP32-CAM (TinyML)
Trained, quantized, and deployed a CNN to an ESP32-CAM microcontroller to classify apples, bananas, and oranges, using TensorFlow/Keras, TensorFlow Lite, Edge Impulse, and Arduino. Shrank the model to ~33KB with full INT8 quantization, reaching 83.3% accuracy on a held-out set (86.2% in float32) and 35–60 ms on-device inference. [Code](https://github.com/haroonwaqar/Fruit-Classification-TinyML-ESP32)

#### ⚽ Football Panel Anomaly Detection
Built a few-shot, unsupervised defect detection pipeline for football panels using DINOv2 and a PatchCore-style memory bank in PyTorch. Trained on only 10 defect-free images with no labeled defects, and caught 95.6% of defects (194/203) on 266 unseen images while producing heatmaps that localize each flaw. [Code](https://github.com/haroonwaqar/Football-Panels-Anomaly-Detection)

#### 🌫️ Sialkot AQI Forecaster
Built an end-to-end serverless MLOps system that forecasts air quality 72 hours ahead for Sialkot, using Python, XGBoost, Hopsworks (Feature Store and Model Registry), GitHub Actions, and Streamlit. Automated hourly feature ingestion and daily retraining, selected the best model from a Ridge / Random Forest / XGBoost comparison, and converted PM2.5 predictions to US EPA AQI health alerts. [Live Demo](https://aqi-prediction-sialkot.streamlit.app/) · [Code](https://github.com/haroonwaqar/AQI-Prediction)
